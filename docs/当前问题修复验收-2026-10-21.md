# 当前问题修复验收（0.3.1）

依据：工作区 `当前问题.md` 与 `Add_data/topics/`。日期：2026-10-21。

## 问题处理

| 原问题 | 修复结果 |
| --- | --- |
| 无参数菜单与帮助重复、入口不清晰 | `zs-support` 直接显示与 `-h` 相同的帮助，不再进入顶层循环菜单。保留 connect/bag/pull 内有具体用途的选择。 |
| rec/bag 等重复展示 | 主帮助与 Tab 补全只展示 connect、info、bag、status、stop、pull、doctor、completion。rec/log/map/collect 保留原参数兼容，子命令帮助说明推荐入口。 |
| q 被当成错误 | 人工菜单输入 q 正常取消并返回 0，不显示“错误”；JSON 取消结构保持兼容。 |
| pull 打印 hashes/path_attempts 等内部字段 | 普通输出仅展示保存位置、文件数量/大小、校验、复用及必要提示。JSON 和 collection-manifest.json 保留完整证据。部分失败、扫描失败、日志变化和不完整录包仍会提示。 |
| 地图不应选择板卡 | pull map 和兼容 map 固定使用 compute，配置中的 board=body 不影响地图。算力板不可达直接提示，不回退本体。组合采集的地图也使用 compute，其余类型仍按 --board 选择。 |

地图命令显式使用 `--board body` 会提示移除该参数，避免与指定来源冲突；正常 `pull map` 不需要 --board。
